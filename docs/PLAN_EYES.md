# План: «Глаза» — экран-адаптер покерного стола (`pokafer/eyes/`)

Компонент читает состояние покерного стола **с экрана** и собирает Snapshot
для мозга. Правила проекта — DECISIONS.md: цель — наш веб-стол (полигон с
ground truth) и приватные play-money комнаты с согласия участников;
реально-денежные румы, борющиеся с ботами, — вне проекта.

## 0. Принцип «подходит почти к любому интерфейсу»

Один движок, сайты отличаются только **пресетами**:

```
движок (pokafer/eyes/)              — универсален, не знает про сайты
пресет сайта (data/eyes/*.toml)     — зоны, шаблоны, тема
реестр (data/eyes/sites.toml)       — домен(ы) → пресет
```

- **Зоны** — в процентах от окна (не пиксели) → переживают resize/DPI/темы.
- **Калибровка нового сайта** — интерактивная разметка кликами
  (`pokafer eyes-calibrate`) + снимки карт/цифр для шаблонов. Без правки кода.
- Определение активного пресета — по домену/порту вкладки (реестр ниже).

### Формат реестра `data/eyes/sites.toml` (скетч)

```toml
[presets.pokafer_local]
url_patterns = ["localhost:8010", "127.0.0.1:8010"]
theme = "dark_felt"                 # палитра для порогов распознавания
calibration = "pokafer_local.toml"  # файл зон (тоже в data/eyes/)

[presets.pokernow_play]
url_patterns = ["pokernow.club"]
theme = "light"
calibration = "pokernow_play.toml"

[domains]
"127.0.0.1" = "pokafer_local"
"localhost" = "pokafer_local"
"pokernow.club" = "pokernow_play"
```

Калибровочный файл (зоны в % от окна):

```toml
[seat.1]        # место: карты, стек, ставка, имя — по отдельным зонам
cards   = [x, y, w, h]
stack   = [x, y, w, h]
bet     = [x, y, w, h]
[board]
slots   = [[x,y,w,h] ×5]
[pot]  area = [...]
[hero] cards = [...]
[meta] dealer_mark = [...]; active_mark = [...]
```

## 1. Модули (`pokafer/eyes/`)

| Файл | Роль |
|---|---|
| `capture.py` | поток кадров области окна (mss), FPS-бюджет |
| `sites.py` | реестр домены→пресет (`sites.toml`), загрузка калибровок |
| `calibrate.py` | интерактивная разметка зон кликами → TOML-пресет |
| `cards.py` | распознавание карт: 52 класса (template match / мини-CNN) |
| `numbers.py` | OCR цифр в зонах (шаблоны шрифтов пресета) |
| `tracker.py` | автомат состояний: улицы, дебаунс анимаций, валидация кадров |
| `snapshot.py` | сборка Snapshot (+confidence) → коннектор мозга |

## 2. Этап 0 — АУДИТ И ПОЛИРОВКА ВЕБ-СТОЛА (перед глазами)

Глаза полагаются на стабильную геометрию и однозначные состояния — стол
сначала приводится в порядок:

- матрица скриншотов: {1..5 ботов} × {1280, 1920 ширина} — без наслоений;
- бейджи действий и фишки ставок не перекрывают карты/имена;
- улица, банк, стеки, чей ход — всегда однозначно читаемы;
- фиксированные позиции мест (глаза = зоны в %);
- `/debug/state` — ground truth endpoint (только для автотестов глаз);
- приёмка: матрица без дефектов + тесты зелёные.

## 3. Этапы глаз

| Этап | Содержание | Приёмка |
|---|---|---|
| 1. Захват + реестр | capture + sites.toml, выбор пресета по домену | кадры идут, пресет выбирается |
| 2. Пресет нашего стола | калибровка зон pokafer_local | зоны совпадают с фактическими |
| 3. Карты | 52-классовое распознавание (шаблоны с нашего рендера) | ≥ 99% на потоке кадров |
| 4. Цифры | OCR стеков/банка/ставок | ≥ 98% на потоке кадров |
| 5. Трекер | автомат улиц/действий, дебаунс | ровно один Snapshot на раздачу-событие |
| 6. Snapshot + автотест | сборка + сравнение с ground truth стола | расхождений 0 на длинной сессии |

## 4. Критерии приёмки компонента

1. Глаза → Snapshot → решение мозга в реальном времени на нашем столе.
2. Точность: карты ≥ 99%, цифры ≥ 98% (автотест против ground truth).
3. Адаптация к «чужому» сайту = пресет + калибровка, без правки кода движка.
4. Snapshot скрывает то, что скрыто на экране (карты оппонентов — None).

## 5. Риски

- Анимации/перекрытия на чужих сайтах → tracker-дебаунс, калибровка.
- Смена темы/масштаба чужого сайта → зоны в %, пороги от пресета.
- Скриншот «мимо окна» → валидация геометрии кадра.
- Соблазн подглядывания: в стол НЕ добавлять скрытых подсказок для глаз —
  иначе автотест теряет смысл (глаза видят ровно то, что видит человек).
