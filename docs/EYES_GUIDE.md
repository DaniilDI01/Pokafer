# Глаза: как устроены и как адаптировать под другой покер-рум

Зачем этот документ: чтобы спустя время (или новому ассистенту) быстро
вспомнить, как глаза читают стол и что именно делает новый рум «новым».
Статус этапов, история и решения — в [PLAN_EYES.md](PLAN_EYES.md) и
[DECISIONS.md](DECISIONS.md) §7. Здесь — устройство и порядок действий.

**Коротко.** Глаза — единственный канал, которым мозг видит стол. Стол
открыт в управляемом браузере; браузер отдаёт кадры, а глаза читают кадр
пикселями. От рума зависят только четыре вещи:

1. **зоны** — где что лежит на странице;
2. **картинки карт этого рума** — 52 шаблона, рубашка, пустые слоты;
3. **фон и формат чисел**;
4. **кнопки** — куда кликать.

Всё остальное (захват, распознавание чисел, клики, зеркало) — общее.

## 1. Путь данных

```
страница рума в браузере глаз (TableBrowser)
        │   кадр страницы -> PIL.Image (у нас 1280×720)
        ▼
perceive(кадр)  ── CardReader:   слоты карт  -> пусто / рубашка / карта / не распознано
        │        └─ NumberReader: зоны чисел  -> сумма / неуверенно / числа нет / пусто
        ▼
Perception — всё, что глаза видят в одном кадре (+ сводка по местам)
        ├──► зеркало (отдельный процесс): человек смотрит, что видят глаза
        └──► трекер 🔜 -> Snapshot -> мозг 🔜 -> Actuator: клик по зоне кнопки
```

**Граница, которую нельзя нарушать:** боевые глаза видят только пиксели
кадра. DOM, команды браузера, внутренние адреса рума — недоступны; они
разрешены только калибровке и тестам (`pokafer/eyes/truth.py`). Нарушить
её — значит обмануть себя: глаза должны работать и там, где внутренности
страницы недоступны или меняются без предупреждения.

## 2. Что переносится на новый рум, а что нет

| Что на экране | Как читается | Что нужно от нового рума | Инструмент |
|---|---|---|---|
| Карты | шаблоны, снятые с самого рума | 52 карты, рубашка, пустые слоты — в пиксель | для нашего стола — `scripts/calibrate_pokafer.py`; для чужого 🔜 сборщик с подписью |
| Числа (стеки, банк, ставки, сумма колла) | готовая модель распознавания текста PP-OCRv5 | только зоны, фон зон, разделитель дроби | 🔜 разметка зон кликами |
| Где что лежит | зоны пресета в пикселях референс-вьюпорта | один фиксированный размер окна | 🔜 |
| Кнопки действий | реальный клик в центр зоны | зоны кнопок + пустая точка для курсора | актатор готов |
| Надписи действий («фолд/колл/чек») | не нужны: действия выводятся из изменений состояния | ничего | трекер 🔜 |

Почему карты — шаблоны, а числа — модель: карта на сайте — картинка, она
печатается одинаково каждый раз. Текст же зависит от шрифта, субпиксельной
позиции глифа и среды; пиксельные шаблоны под текст пришлось бы снимать и
отлаживать на каждом сайте. Готовая модель читает любой шрифт (проверена на
11 шрифтах нашего стола, 99.98%) и в настройке не нуждается.

## 3. Модули (`pokafer/eyes/`)

| Файл | Роль |
|---|---|
| `browser.py` | управляемый браузер: точный вьюпорт, кадры страницы, реальные клики и клавиатура, надёжное закрытие |
| `capture.py` | `WindowHidden` (окно свёрнуто) и съём с монитора — запасной путь |
| `sites.py` | реестр «домен → пресет»; чтение пресета, перевод долей в пиксели |
| `slots.py` | перечисление слотов карт пресета: герой, борд, места |
| `cards.py` | `CardReader`: слот → пусто / рубашка / карта / не распознано |
| `numbers.py` | `NumberReader` + `OcrEngine`: зона → сумма; разбор формата |
| `perceive.py` | **ядро**: один кадр → все чтения (`Perception`) |
| `loop.py` | цикл зрения: кадр → perceive → подписчикам зеркала |
| `actuator.py` | действия по зонам пресета реальными кликами |
| `mirror.py`, `viewer.py`, `viewer_page.html` | зеркало «что видят глаза» |
| `truth.py` | правда нашего стола для калибровки и тестов (**не рантайм**) |
| `tracker.py`, `snapshot.py`, `calibrate.py` | 🔜 трекер, Snapshot, разметка чужих сайтов |

## 4. Пресет: всё, что в руме «своё»

Пресет — это один TOML-файл и папка шаблонов карт. Реестр —
`data/eyes/sites.toml`: новый рум = запись в `[presets]` + строка в
`[domains]`.

```toml
[presets.some_room]
url_patterns = ["some.room"]              # не используется при выборе, справочно
calibration = "some_room.toml"            # файл пресета в data/eyes/
card_templates = "some_room"              # папка data/eyes/templates/some_room/

[domains]
"some.room" = "some_room"                 # по ЭТОМУ пресет выбирается по адресу страницы
```

Выбор идёт по домену адреса страницы (порт отбрасывается). Файл пресета
ниже — схематично, вместо `x, y, w, h` стоят числа; живой пример —
`data/eyes/pokafer_local.toml`:

```toml
[meta]
viewport_ref = [1280, 720]   # размер страницы, при котором сняты зоны и шаблоны
coords = "ref_px"            # зоны — пиксели этого вьюпорта
calibration_id = "…"         # зоны и шаблоны от одной калибровки; читатели сверяют его
seat_layouts = [[…], …]      # только наш стол: где сидят боты по их числу (для тестов)

[hero]
cards = [[x, y, w, h], [x, y, w, h]]   # слоты карт героя
stack = [x, y, w, h]                  # зона ЧИСЛА стека
name  = [x, y, w, h]                  # имя (пока не читается — на будущее)
bet   = [x, y, w, h]                  # число на фишке ставки героя

[board]
slots = [[…], […], […], […], […]]     # пять слотов борда

[pot]
amount = [x, y, w, h]                 # число банка
area   = [x, y, w, h]                 # банк целиком (на будущее)
[street]
area   = [x, y, w, h]                 # надпись улицы (на будущее)
[result]
area   = [x, y, w, h]                 # итог руки (на будущее)

[seat.<место>]                        # по разделу на каждое место; имена произвольны
                                      # (у нас pos_top, pos_left, pos_right, pos_tl, pos_tr)
cards = [[…], […]]                    # слоты вскрытых карт
backs = [[…], […]]                    # слоты рубашек
stack = [x, y, w, h]
name  = [x, y, w, h]
bet   = [x, y, w, h]

[act]                                 # кнопки: клик приходится в центр зоны
fold = [x, y, w, h]                   # кнопка «Фолд»
check = [x, y, w, h]                  # кнопка «Чек / Колл»
raise = [x, y, w, h]                  # кнопка «Рейз / Ставка»
slider = [x, y, w, h]                 # слайдер и поле суммы рейза
input = [x, y, w, h]
preset_min  = [x, y, w, h]           # готовые размеры: мин, ½ банка, банк, олл-ин
preset_half = [x, y, w, h]
preset_pot  = [x, y, w, h]
preset_max  = [x, y, w, h]
next = [x, y, w, h]                   # «Следующая рука» (на нашем столе)
call_amount = [x, y, w, h]            # число на кнопке «Колл N»
park = [x, y, w, h]                   # пустая точка: сюда уходит курсор после клика

[numbers]                              # зона числа -> яркость фона ЗОНЫ, когда её элемент показан
"hero.stack" = 38.0
[numbers_format]
decimal = "."                          # разделитель дроби на этом руме
```

В файле все координаты записаны **долями** референс-вьюпорта (x/1280,
y/720, шесть знаков); при чтении они превращаются обратно в целые пиксели.

**Шаблоны** — `data/eyes/templates/<card_templates>/`:

| Файл | Что это |
|---|---|
| `card_<ранг><масть>_<ш>x<в>.png` | карта; по одному файлу на каждую из 52 карт **на каждый класс размеров** (у нас 58×82 для героя и вскрытых карт, 46×66 для борда) |
| `back_<ш>x<в>.png` | рубашка (может быть несколько — по размеру) |
| `empty_<путь слота>_<номер>.png` | как выглядит пустой слот (сукно под ним): `empty_board.slots_2.png`, `empty_seat.pos_top.cards_0.png` |
| `calibration_id` | одна строка; обязана совпадать с `meta.calibration_id` |

Как читается слот (`CardReader.read`): кроп сравнивается с эталоном пустого
слота (совпал — «пусто»), затем с рубашками, затем с 52 картами своего класса
размеров. Сравнивается только внутренность карты (кромка 2 px и скруглённые
углы не считаются — там мешается сукно). Совпадение — не больше 6% отличий
по «чернилам»; иначе «не распознано» с названием ближайшей карты. Кроп другого
размера, чем любой шаблон, — сразу «не распознано».

Как читается число (`NumberReader.read`): если яркость зоны отличается от
записанного фона сильнее чем на 14 — элемента нет («пусто»); иначе зона
обрезается по содержимому, увеличивается и подаётся модели. Модель читает
всю зону как одну строку, поэтому **в зоне должно быть только само число**
(знак валюты вплотную — можно). «Чек» без суммы даёт «числа нет», а не ноль.
Суффиксы «k/m» и «к/м» понимаются; если в зоне несколько чисел, берётся
самое длинное.

**Один `calibration_id` — одна калибровка.** Зоны и шаблоны снимаются
одновременно; читатель отказывается работать, если идентификаторы разные.
Для пресета, собранного вручную, подойдёт любая уникальная строка — лишь бы
она совпадала в обоих местах.

## 5. Правила, без которых чтение ломается

Все они получены из неудач на нашем столе.

- **Геометрия фиксированная.** Позиции элементов — целые пиксели и не
  зависят от содержимого (табличка места не должна менять ширину от имени
  игрока, борд не перецентрироваться). Иначе зона промахивается.
- **Карты печатаются пиксель в пиксель.** Анимация, подсветка, наложение
  таймера, полупрозрачность, масштаб — и шаблон не совпадёт.
- **Окно одного размера.** Вьюпорт обязан равняться `viewport_ref`. Таскать
  и перекрывать окно можно свободно; свёрнутое окно глаза разворачивают
  сами. Изменение размера они пока **не** перехватывают — чтение ломается
  (возврат размера отложен).
- **Курсор уходит с кнопки.** Оставленный на кнопке, он держит подсветку
  наведения, фон зоны числа меняется, и глаза решают «элемента нет». Актатор
  после каждого клика убирает курсор в `act.park`.
- **Зона числа начинается там, где начинаются цифры**, и не захватывает
  подписи рядом.
- **Шаблоны привязаны к машине.** Рендер зависит от видеокарты и шрифтов:
  калибровку, снятую на одной машине, на другой повторить
  (`python scripts/calibrate_pokafer.py`, ~70 с). Читатель не даст молча
  смешать шаблоны разных калибровок.
- **Не подглядывать.** В стол не добавлять скрытых подсказок для глаз.

## 6. Новый рум: порядок действий

**Шаг 0 — границы и совместимость.** Рум — приватный, на play-money, с
согласия участников; румы на реальные деньги, борющиеся с ботами, — вне
проекта. Смотрим, годится ли стол в принципе:

- открывается в обычном Chrome и держит раскладку при одном размере окна;
- карты — статичные картинки, без постоянной анимации;
- числа — обычный текст (у нас цифры высотой 9–13 px; заметно мельче — проверять);
- у клиента есть масштаб или зум — выставить один и не трогать.

**Шаг 1 — реестр.** Записать рум в `data/eyes/sites.toml` и завести файл
пресета `data/eyes/some_room.toml` (поля — по ходу шагов 3–5).

**Шаг 2 — первый взгляд.** Открыть рум в браузере глаз и снять кадр; заодно
войти в аккаунт (профиль сохранит логин между запусками; держите его вне
репозитория — там куки):

```python
from pathlib import Path

from pokafer.eyes.browser import TableBrowser

profile = Path.home() / ".cache/pokafer/profiles/some_room"      # абсолютный путь, без «~»
with TableBrowser("https://some.room/table/123", viewport=(1280, 720),
                  profile_dir=str(profile)) as browser:
    input("Войдите в аккаунт, откройте стол и нажмите Enter…")   # браузер открыт и ждёт
    browser.screenshot().save("room.png")
```

Размер вьюпорта — тот, что потом попадёт в `viewport_ref`.

**Шаг 3 — зоны.** Разметить по кадру `room.png`: слоты карт, зоны чисел
(только число), кнопки, пустую точку для курсора. Инструмент разметки
кликами — 🔜; пока координаты снимаются по снимку в любом редакторе
картинок (курсор показывает пиксели). Координаты переводятся в доли:
`x / ширина`, с шестью знаками.

**Шаг 4 — карты.** Собрать с рума 52 карты, рубашку и пустые слоты в тех
слотах, где они бывают в игре, и сохранить шаблоны с именами из §4.
Сборщик с кластеризацией и ручной подписью — 🔜. Пока это делается руками:
снять кадры за несколькими раздачами и вырезать кропы по слотам.

**Шаг 5 — числа.** Записать яркость фона каждой зоны при показанном
элементе (медиана яркости кропа) в `[numbers]` и разделитель дроби в
`[numbers_format]`. Под шрифт ничего настраивать не нужно.

**Шаг 6 — проверка.** Запустить `pokafer eyes-demo --url <рум>` и смотреть
зеркало: зелёное прочитано, красное — нет. Правды у чужого рума нет, поэтому
критерий — визуальный; журнал с ручной подписью образца — 🔜.

**Шаг 7 — игра.** Чтобы бот ходил сам, нужны трекер (чиная с «видна ли
кнопка действий»), Snapshot и бой — 🔜.

**Первый шаг без самого рума.** Есть идея исследователя: по 5–10 скриншотам
настоящего рума сделать тему нашего веб-стола (палитра, карты, шрифты,
раскладка) и калибровать глаза на ней — с правдой и без риска для аккаунта.
Для этого нужна параметризация темы стола и разметка зон на произвольной
раскладке. Это удобный способ проверить глаза на «чужом» виде раньше, чем
появится доступ к руму.

## 7. Честный статус для чужого рума

**Работает без переделки:**

- захват кадра у любого сайта в Chrome, в том числе без видимого окна;
- реальные клики и клавиатура;
- распознавание чисел — модель проверена на 11 шрифтах нашего стола, на
  настоящих румах ещё нет;
- чтение карт — при шаблонах, снятых с этого же рума в том же окне;
- зеркало.

**Что может потребовать правки:** сводка карт по местам
(`perceive._seat_cards`) рассчитана на нашу раскладку — у места два слота
открытых карт и внутри них два слота рубашек. При другой структуре места её
надо поправить.

**Не сделано:** разметка зон кликами, сборщик шаблонов карт, трекер,
Snapshot, бой. На настоящем руме глаза ещё не запускались.

**Ожидаемые сложности:** анимации раздачи (нужна выдержка перед кадром),
масштаб клиента, всплывающие окна, подсветка при наведении.

## 8. Симптом → причина

| Что видно | Скорее всего |
|---|---|
| Все карты «не распознано» | шаблоны не от этого рума или не от этой калибровки; окно другого размера |
| «Не распознано» только в игре, а на неподвижном кадре читается | анимация: кадр снят раньше, чем карта встала |
| Числа «пусто», хотя число есть | фон зоны записан неверно; зона не там; кнопка подсвечена курсором |
| Ложное число на пустом месте | в зоне оказался соседний текст |
| В терминале «окно стола было свёрнуто — развернул» | так и задумано; чтобы окна не было совсем — `--headless` |
| На другой машине всё «не распознано» | шаблоны сняты на другой видеокарте: перекалибровать |
| Всё сломалось после изменения размера окна | вернуть окно к `viewport_ref` |

```bash

pokafer table --port 8011 --bot-think 0.05      # стол для калибровки и тестов
```
